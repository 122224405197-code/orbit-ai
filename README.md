# Orbit AI - Your Life Tracker

A comprehensive Flutter mobile app for tracking productivity, goals, habits, health, finance, and more.

## Features

- 📊 **Dashboard** - Overview of your productivity score, tasks, and goals
- ✅ **Tasks** - Manage daily tasks and schedules
- 📅 **Calendar** - Track events and deadlines
- 🎯 **Goals** - Set and monitor progress on your goals
- 💪 **Habits** - Build and track daily habits
- 🏥 **Health** - Monitor health metrics
- 💰 **Finance** - Track expenses and budget
- 📝 **Notes** - Keep quick notes
- 🤖 **AI Assistant** - Get personalized recommendations

## Getting Started

### Prerequisites

- Flutter SDK (3.0.0 or higher)
- Dart SDK
- Android Studio or Xcode

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd orbit-ai
```

2. Install dependencies
```bash
flutter pub get
```

3. Run the app
```bash
flutter run
```
